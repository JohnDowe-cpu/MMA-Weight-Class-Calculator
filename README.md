# MMA Fighter Tracker

A Python command-line application that allows users to create MMA fighter profiles, automatically determine weight classes, save profiles to a text file, display saved fighters, and search fighters by name.

This project began as a simple weight class calculator and was progressively refactored into a modular menu-driven application while practicing core Python programming concepts.

---

## Features

- Create fighter profiles
- Automatically determine MMA weight classes
- Input validation with `try/except`
- Save fighter profiles to a text file
- View all saved fighters
- Search fighters by name
- Case-insensitive search
- Menu-driven command-line interface

## Installation

Clone the repository:

```bash
git clone [https://github.com/YOURUSERNAME/repository-name.git](https://github.com/JohnDowe-cpu/MMA-Weight-Class-Calculator/edit/main/README.md)
```

Navigate into the project:

```bash
cd MMA-Weight-Class-Calculator
```

Run:

```bash
python weight_class_calculator.py
```
